# Competition Rules Compliance Matrix (2026 FinTechathon International Track)

This project follows the user's uploaded **PBCSF Appendix 2 - Problem Description and Competition Rules for International Track** (4 pages), previously supplied for private review. The public release does not redistribute the third-party PDF. Refer to the competition's official published rules and privacy policy.

## Topic C

Official topic: "Cross-border & Student Finance Assistant" - remittances, tuition payments, credit building and multi-currency management. StudentBridge AI supports those use cases as follows: cross-border tuition planning with a quote-aware optimized ranking; multiple currencies and historical reference FX API; personal financial digital twin; credit-readiness education; secure sandbox execution.

## Judging weights

- **Task completion 40%:** end-to-end user inputs -> decision plan -> risk check -> user approval -> test transaction -> receipt -> audit event.
- **Security & compliance 30%:** controls and explicitly documented limitations. Does not claim KYC/AML screening or regulatory certification; blocking unsafe inputs and approval checks can be demonstrated.
- **Innovation & interaction 30%:** deadline-constrained optimizer, reserve-aware Digital Twin, source-linked Decision Passport, six-country choice, responsive dashboard and grounded copilot.

## Submission materials required (page 3)

1. Technical documentation - provided as system design `.md` and `.pdf`.
2. Presentation - `docs/submission/StudentBridge_AI_Presentation.pptx`. Keep spoken presentation under 10 minutes.
3. Demo video - optional standalone demo, max 5 minutes; not recorded in package.
4. Source code, README, repository link, deployment directions, test cases - all provided locally except live GitHub link. **Publish to GitHub yourself**.
5. Security self-assessment - in PDF and Markdown, with permission tiers and risks.
6. Execution evidence for non-on-chain topic - sample simulated-account ledger and logs. A real **screen demonstration video still needs recording and submission**.

## Administrative requirements (page 3-4)

- Teams of 2-5 students; 60% or more non-Chinese nationals for the International Track, and eligible international institutions.
- English for presentations, submissions and reviews.
- October 20, 2026 23:59 Beijing time (October 20, 2026 21:59 Bangladesh time) deadline.
- Only one team per participant; independent original work, properly licensed sources, and no plagiarism.
- Finalists: at least one member must attend in person or risk forfeiture of awards.

The submission package **is not automatically submitted** and does not imply the student's eligibility or source-license review has been completed.
