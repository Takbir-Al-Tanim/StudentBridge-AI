# Five-Minute Demo Recording Script (record yourself)

The organizer requests sandbox execution evidence and demo video for Topic C. The standalone video is optional but, if included, keep it at or under 5 minutes. This package includes a storyboard; **no video is recorded**.

**0:00–0:30 — Problem.** "Students studying across borders face currency, tuition, bank fees, deadlines, budgeting and unfamiliar credit systems. StudentBridge AI brings those decisions into one explainable workflow."

**0:30–1:00 — Coverage.** Show six-country selector, swap countries, try **China → Australia**, then **Japan → UK**, showing how the same platform handles both. Explain 30 *theoretical* directions, not 30 verified bank routes.

**1:00–1:50 — Real published data.** Select University of Melbourne's 2026 Master of TESOL example (AUD 48,992 per EFTSL) and open the official linked PDF. Fetch live Frankfurter FX if internet is available, emphasizing reference FX is not a confirmed bank quote. If offline, show the unavailable state and continue.

**1:50–2:45 — Decision optimizer.** Enter a documented provider quote obtained directly from the provider for the actual corridor. If using numbers only for the recording, explicitly label them **test inputs, not actual quotes**. Show fee calculation, deadline check, emergency reserve and rejected cheaper-but-late route. Download the explainable Decision Passport.

**2:45–3:25 — Digital Twin.** Change FX shock +5%, add extra fee, compare baseline and stressed payment costs, show whether emergency reserve survives. Explain this is scenario testing, not an FX prediction.

**3:25–4:05 — Country credit guidance.** Open Australia and Japan in the Credit Navigator, click source links, explain that no credit scores or lending approvals are invented.

**4:05–4:45 — Sandbox action.** Click review on the conditionally viable test quote. Read 'NO REAL MONEY' warning, check approval, simulate the payment, and open the transaction/audit screen.

**4:45–5:00 — Close.** Show the three innovations: EduRoute constraints + Digital Twin + Decision Passport. Say the project supports 30 country selections but requires independently verified providers before real transfer recommendations. This honesty and auditability are important design features.

Do not show API keys, private student documents, passwords, account identifiers, or personal financial statements on screen.
